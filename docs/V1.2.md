# v1.2

Adds the research-grade geography/codebook/provenance layer, IndexedDB v4,
worker analytics, provenance export, PWA shell caching, and GitHub Pages
deployment/refresh workflows.

Before the first production refresh, set the repository variable `SV_SOURCE_URL`
to the exact authoritative SlaveVoyages CSV endpoint. The bundled bootstrap
snapshot is not presented as a replacement for that authoritative release.
