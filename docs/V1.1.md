# v1.1 — authoritative-source ingestion hardening

The production ingestion target is the expanded Trans-Atlantic Slave Trade Database download listed by SlaveVoyages as `tastdb-exp-2019.csv`. SlaveVoyages states that the expanded download contains substantially more variables than the online interface; the 2023 codebook documents technical, data and imputed variables.

## Canonical strategy

The pipeline keeps two layers:

1. `fields`: every source column, normalized by a deterministic key, so no unrecognized source variable is silently discarded.
2. Promoted fields: stable dashboard fields such as `voyageid`, `yearaf`, `yearam`, `yeardep`, `tslavesd`, `slaximp`, `slaarriv`, `slamimp`, geographic fields and carrier fields.

## Evidence discipline

Observed/data variables and imputed variables are never silently combined. The metric registry records the exact source field, aggregation and evidence class. In particular, `TSLAVESD` and `SLAXIMP` represent different evidentiary concepts and must be presented separately.

## Reproducibility

A refresh records:

- source URL
- source dataset identifier
- source SHA-256
- source byte count
- source column count
- record count
- duplicate IDs skipped
- pipeline version
- validation report
- per-chunk SHA-256
- artifact SHA-256

## Geographic normalization

SlaveVoyages' codebook defines geographic codes and relationships between voyage stages. The raw coded values are retained first. A later enrichment layer can attach names/coordinates without changing the original source value.

## Important distinction

The 2019 expanded download and the current online interface are not assumed to be identical releases. The dashboard therefore exposes the dataset version and provenance rather than claiming that a historical download is a live mirror of the website.
