# v1.0 production architecture

## Research reproducibility

A release is defined by its manifest, source SHA-256, schema version, generation timestamp and deterministic delivery chunk hashes. Browser analytics operate only on the locally synchronized canonical projection.

## Important analytical rule

Observed and imputed variables remain separate. Database-level imputation must not be described as the same thing as the separate SlaveVoyages Estimates product.

## Deployment constraint

The browser has zero runtime package dependencies. GitHub Pages serves static assets only. The data-refresh job runs Python in GitHub Actions; Python is not required by the deployed application.
