# Analytical modes

## Database mode
The voyage database represents documented voyage records plus clearly labelled imputed variables. It should be used when the question concerns the characteristics of voyages in the database.

## Estimates mode
Estimates are a separate product. SlaveVoyages explains that the Estimates section aggregates voyage-database information by embarkation/disembarkation region and also incorporates published regional series when those provide more accurate estimates of total trade volume. Therefore estimates must never be presented as if they were simply a sum of the voyage records.

The production UI should expose Database and Estimates as separate modes with separate provenance, methodology, and denominators.
